## Changes

- Vendor and wholesale product forms save a subcategory. The pack/unit field distinguishes different weights. Each saved barcode must identify a single product in its store. When packages have the same printed barcode, assign a distinct internal item code for one of them and use that code at checkout.
- Vendor checkout lets a cashier edit quantity and the final selling price for each line. Price edits are recorded on that bill without changing the saved inventory price. The API checks stock, decimal precision and the product MRP. Automatic product discount does not apply again to an overridden final price.
- Reports have moved into vendor Dashboard and wholesale Overview. Account, Settings, Support and Employees are available from Profile instead of separate navigation entries. Both dashboards display the support contact panel.
- Wholesale subscription pricing is now editable from the admin Pricing page as well as Super admin. Only accounts with the Pricing permission can save it.
- The vendor wholesale return form keeps a stable form reference during its async submission, fixing the `Cannot read properties of null (reading 'reset')` error.

# ShopKeeper subscription, access and wholesale update

## New behavior

- Super admin navigation includes **Subscription approvals** at `/app/subscription-approvals`. A request becomes approvable after the vendor submits both the payment reference and screenshot.
- Inventory products may have an empty barcode. At Point of sale choose **Product name**, type a name, and choose the result. No products are displayed before text is entered.
- Super admins assign granular permissions while creating or editing administrators. The server filters store data and blocks disallowed write endpoints. Permission updates end that administrator's current sessions.
- Every password field has a show/hide control, including vendor, administrator, super-admin and wholesale seller logins and account password forms.
- Super admins create wholesale seller accounts in **Super admin**. Sellers sign in at `/wholesale/login`.
- Vendors use **Wholesale** to browse seller products, enter required quantities and submit requests.
- Wholesale sellers manage products, requests, request status, transactions and refunds in their separate console.
